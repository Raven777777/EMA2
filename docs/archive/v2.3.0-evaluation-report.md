# EMA2 v2.3.0 软件评价报告
## 一、基本信息

- **软件版本**：EMA2 v2.3.0（Rust 单文件 `ema2.exe` + MV3 扩展）
- **测试时间**：2026-10-21
- **测试环境**：Windows 11 + Edge 155，扩展已连接（端口 7744）
- **测试方式**：真实前台 Edge 真机实测，覆盖核心命令与典型交互场景
- **综合评分**：**8.5 / 10**
- **总体结论**：**推荐采用**。核心链路可靠、错误处理成熟、AI 适配度明显优于同类方案；主要改进空间集中在脚本语法文档与 `--help` 完整性。

> 一句话结论：EMA2 把“AI 通过 shell 控制真实 Edge”做得克制且扎实——输出协议对 AI 友好，错误处理一流水准，真机可用性高；主要短板是文档与脚本语法的小坑。

## 四、主要优点

1. **输出协议为 AI 设计**：行式 `key=value`、TSV、ref 体系，错误统一为 `error/msg/hint`，hint 可直接指导下一步修复。
2. **错误处理成熟**：实测多种错误均能返回可执行提示，AI 收到错误后可自修复，无需频繁查文档。
3. **settle 语义设计成熟**：明确区分“失败”与“仍在导航”，`changed=url,title,reload,dom` 精确报告副作用，可观测性强。
4. **ref 带文档版本号**：如 `e17@d248`，跨导航自动失效，从机制上降低误点旧元素风险。
5. **真实浏览器红利**：使用真实前台 Edge，自带登录态与指纹，不依赖 CDP 调试端口，不需要 MCP 配置，一条 `ema2 server` 即起。
6. **部署极简、安全边界清晰**：单文件 exe + MV3 扩展，仅本机回环 7744，无 token 授权面。
7. **工程纪律好**：`ok=1/1`、`settle=pending`、`nav=none`、`retried=1` 等状态如实上报；公开已知弱点与“明确不做”清单，边界意识好。
8. **会话边界清晰**：`--session` 只清理本会话打开的标签，不破坏用户现场。

## 五、问题与改进建议（按严重度）

1. **`.ema2` 脚本语法文档不足，且与 CLI 不一致**
   - 实测 `open`、`wait`、`waitFor time 1s` 报 `unknown action` / `expected key=value`。
   - 脚本只接受 act 动作与 `waitFor`；脚本内 `waitFor` 仅支持 `url|status|timeout`，与 CLI `wait` 的 `text/textGone/selector/time/idle` 语义不同。
   - `AGENTS.md` 与实际行为不一致，`--help` 未列出脚本动作白名单。
   - **建议**：在 `act --help` 与 `AGENTS.md` 中给出脚本动作白名单、完整语法示例，并明确脚本与 CLI 的差异。

2. **`--help` 信息不足、参数风格不统一**
   - `ema2 act --help` 未说明 `fill <ref> <text>` 的位置参数格式；`act` 不接受 `--ref`，而 `files upload` 只接受 `--ref`。
   - **建议**：补齐 `--help` 示例，统一参数风格或在文档中明确例外。

3. **超时参数单位未标注**
   - `open --timeout` 与 `js --timeout` 均为秒，但文档只写 `[--timeout N]`，容易误传毫秒值。
   - **建议**：文档写明单位；报错信息已提示合法范围，可保留。

4. **小瑕疵**
   - `read --mode md` 对 Bing 结果页有序列表全部渲染为 “1.”，编号丢失。
   - `snapshot --filter links` 会混入 button。
   - annotate 输出中同一元素出现重复 ref（如 e23/e24），Edge“翻译”按钮出现负坐标。
   - 扩展连接依赖手动：会话开始时可能 `extension=disconnected`，daemon 无法自动拉起扩展重连，首次接入需在扩展 popup 手动配置端口。

5. **依赖窗口前台**
   - 截图/可见性相关操作要求窗口在前台，这是 `captureVisibleTab` 的固有限制；文档有说明，但多任务并行时会互抢焦点。

## 六、结论

EMA2 是同类工具（browser-use / Playwright-MCP 等）中定位独特的一个：**不做新浏览器实例，而是把正在使用的真实 Edge 变成 AI 的手脚**。核心链路（读、看、点、填、等、观测）在真机上全部顺畅，错误处理和输出协议明显下了功夫，工程纪律超出个人项目平均水平。

**综合评价：8.5 / 10，推荐采用。** 修掉脚本语法文档与 CLI 一致性这个最大坑后，可到 9 分。建议配合 `ema2 init` 文档使用，以规避脚本语法差异。
